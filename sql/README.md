# PostgreSQL & SQL Analysis

This folder contains the SQL analysis used in the Retail Analytics project.

The PostgreSQL workflow includes:

- KPI calculations
- Revenue and order analysis
- Customer segmentation
- Product and category analysis
- Regional performance analysis
- Sales channel analysis
- Customer-level analysis
- Repeat-customer analysis using CTEs
- Year-over-year analysis using window functions
- Conditional aggregation using CASE
- Discount analysis
- Data quality validation
- Referential-integrity checks

The main SQL script is:

`retail_analytics_queries.sql`
